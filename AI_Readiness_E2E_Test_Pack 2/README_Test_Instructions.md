## Suggested intake values

Industry: Professional Services
Company Size: 100-500 employees
Departments: Sales & Pre-sales, Customer Support, Operations, Compliance & Governance
Current Tools: Salesforce, Microsoft Excel, Jira Service Desk, SharePoint, Slack
Cloud Preference: Azure or Cloud-agnostic
Compliance Requirements: GDPR, SOC2 Type II
Pain Points: Manual Process Overload, Data Silos, Slow Support Response Times, Compliance Audit Stress
AI Goals: Efficiency / Cost Reduction, Enhanced Customer Experience, Governance Readiness

Strategic Objective:
Identify the most practical AI pilot to reduce proposal preparation time, improve approved content reuse, streamline support triage, and keep all client-facing outputs under human review.

## Expected system outputs

The system should identify:

- Recommended first pilot: Intelligent Pre-Sales Proposal Copilot
- Secondary use cases: Support Triage Router, Billing Excel Extraction Agent, Contract Audit Assistant
- Evidence signals from proposal workflow, support triage delay, billing reconciliation, and governance checklist
- Risks: PII/client data leakage, hallucinated proposal or billing claims, missing audit logs, low-confidence outputs
- Controls: source citations, redaction, human review, approval workflow, confidence thresholds, audit logs
- Commercial strategy: Pilot MVP Build with indicative pricing and implementation architecture
